# beyond FORM+

An interactive, single-page exploration of generative design and emergence, created for Make It Configurable by Gu, Maia, Sang-a + E-Man.

## Run locally

This website uses plain HTML, CSS, and JavaScript. No build or installation is required. Serve this directory with any static web server, for example:

```sh
python -m http.server 8000
```

Open http://localhost:8000. The entry point is `index.html`; styles, scripts, and images are under `assets/`.

## Features

- Sticky section navigation with current-section highlighting
- Neighbourhood, Growth, and Territory experiments
- Reflection connection activity with Shuffle, Reset, and marked path crossings
- Browser-local progress storage
- Research and Chicago-style source references
